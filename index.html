Connect AuraAttend to your Firebase Cloud Project to sync all student profiles, shared timetables, and attendance logs securely. This allows any student on any device to access the same templates and mark attendance!

Connection Status: Disconnected (Local Mode)

How to get Firebase Config:

  1. Go to Firebase Console.
  2. Create a new project named AuraAttend.
  3. Under Project Shortcuts, click the Web icon (</>) to add an app.
  4. Copy the firebaseConfig JSON object and paste it above.
  5. In your Firebase Project sidebar, go to Build > Firestore Database and click Create database (choose "Start in test mode" so everyone can write/read templates).
